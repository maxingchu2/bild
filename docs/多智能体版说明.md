# 船舶检验多智能体版说明（main_multi_agent.py）

基于 LangGraph Supervisor 模式，按 ship-inspection.html（船舶检验智能体工作台）的业务域拆分了 5 个智能体，由调度员自动路由并形成调用链。

## 架构

```
START
  ↓
supervisor（调度员 LLM，结构化输出选择智能体）
  ├→ task_agent     任务查询：待办任务、船舶信息
  ├→ prepare_agent  检验前准备：新增/删除检验项、生成检验前准备单
  ├→ archive_agent  记录归档：确认遗留复查项、归档记录
  ├→ report_agent   报告写作：检验报告、处置建议
  └→ general_agent  通用问答：CCS 规范、常见问题
        ↓ （各智能体内部为 agent ⇄ tools 自动循环，直到无工具调用）
       END
```

## 运行

```bash
pip install -r requirements.txt
python main_multi_agent.py
# 浏览器打开 http://localhost:8000        （简易流式测试页）
# 浏览器打开 http://localhost:8000/ship   （船舶检验智能体页面，样式功能与原版一致）
```

## 船舶检验智能体页面（/ship）

`static/ship-inspection.html` 基于原编译页面做了最小改动接入后端，功能和页面样式与原版完全一致：

- 登录、快捷按钮（查询待办/待准备/归档任务、保存/生成/新增/删除检验项等）、任务卡片跳转等原有脚本化功能全部保留
- 在以下位置将**自由输入的对话**接到了 `/api/chat` 多智能体后端（SSE 流式渲染）：
  - 船检智能体首页对话框（非快捷查询的输入走 AI）
  - 检验前准备页对话框（未命中 新增/删除/保存/生成 关键词的输入走 AI）
  - 归档记录页对话框
- 对话历史（`window.__aiHistory`）全量随每次请求发送，支持多轮上下文
- 若直接以 file:// 打开页面，会自动请求 `http://localhost:8000/api/chat`（服务端已开启 CORS）
- 点击"新建对话"会清空 AI 上下文与页面对话，并自动让智能体从 CSV 查询待办任务、逐步引导完成检验流程

## CSV 数据接口

业务数据存放在 `data/` 目录的三个 CSV 文件中（相当于数据接口，对接时替换为数据库/Java 服务）：

- `data/ships.csv`：船舶基础信息与状态（船名、CCSNO、船舶类型、建造日期、检验类型、状态）
- `data/inspection_items.csv`：各船检验项（船名、编号、名称、类别）
- `data/legacy_issues.csv`：遗留复查项（船名、编号、问题、状态）

服务启动时读取 CSV；新增/删除检验项、确认遗留项、归档等操作会实时写回 CSV，重启后数据保留。

接口契约与原版完全一致（`POST /api/chat`，SSE 事件 `reasoning`/`content`/`error`/`[DONE]`），前端 static/index.html 零改动。调度过程与工具执行会实时显示在灰色思考区，如：

```
[调度至 检验前准备智能体：新增/删除检验项、生成检验前准备单]
[执行工具 generate_preparation_sheet，参数 {"ship_name": "远洋之星"}]
[工具 generate_preparation_sheet 返回: {...}]
```

新增辅助接口：`GET /api/agents` 返回智能体清单。

## 示例问题

| 问题 | 路由到 | 自动执行的工具 |
| --- | --- | --- |
| 查询所有待办任务 | task_agent | query_pending_tasks |
| 远洋之星的船舶信息 | task_agent | query_ship_info |
| 给远洋之星新增检验项"卫星应急示位标（救生）" | prepare_agent | add_inspection_item |
| 生成远洋之星的检验前准备单 | prepare_agent | generate_preparation_sheet |
| 确认远洋之星的遗留项 L1 和 L2 后归档 | archive_agent | confirm_legacy_issue ×2 + archive_record |
| 写一份外板测厚减薄超标的处置建议 | report_agent | （可查船舶信息后撰写） |
| 消防泵压力不足常见原因 | general_agent | 无 |

归档有业务校验：遗留复查项未逐条确认时 `archive_record` 会拒绝归档并列出未确认项，智能体会自动提示先确认。

## 模拟数据与对接真实系统

`SHIPS` 字典是内存模拟数据（远洋之星/东海明珠）。对接真实系统时，把各 `@tool` 函数体替换为调用你的数据库或 Java 后端 HTTP 接口即可（如 `httpx.get("http://java-backend/api/ships/...")`），智能体逻辑无需改动。

## 关于 ship-inspection.html

该文件是编译后的纯前端演示页（Vue 构建产物），页面内的对话与数据均为前端内置模拟，**没有调用任何后端接口**。要让它真正接入本服务，需要其源码工程把对话发送逻辑改为调用 `POST /api/chat`（请求/SSE 格式见 docs/后端对接文档.md），前端解析 `reasoning`/`content` 事件渲染即可。如能提供该页面的前端源码，可以直接帮你接好。
